Panduan Integrasi REST API
User Service

Dokumentasi teknis lengkap khusus Frontend Engineer untuk mengintegrasikan autentikasi, refresh token rotation, profil pengguna, dan penanganan error pada platform Pre-Loved Marketplace.

Base URL Service http://localhost:3001
API Prefix /api/v1
Format Data JSON (application/json)
Autentikasi JWT Bearer Token
Interactive Docs /api-docs (Swagger UI)
Status Version v1.0.0 (Production-Ready)
1 Standar Komunikasi & Format Response

Semua endpoint REST API User Service mengembalikan struktur JSON yang seragam dan konsisten. Frontend developer dapat membuat tipe umum (*generic response interface*) di TypeScript.

Struktur Response Sukses (2xx)

{
  "success": true,
  "message": "Deskripsi status operasi yang berhasil",
  "data": { ... }
}

Struktur Response Gagal (4xx / 5xx)

{
  "success": false,
  "message": "Pesan kesalahan yang deskriptif untuk ditampilkan di UI",
  "errors": null // atau array detail error jika validasi input gagal
}

Daftar HTTP Status Codes

Kode Status Arti Tindakan di Sisi Frontend
200 OK Permintaan berhasil Perbarui state / render data ke komponen UI.
201 Created Resource berhasil dibuat Navigasikan user (misal: redirect ke halaman login atau dashboard).
400 Bad Request Validasi input tidak sesuai Tampilkan pesan error validasi di form input terkait.
401 Unauthorized Token hilang, kedaluwarsa, atau sesi dicabut Picu alur Refresh Token otomatis. Jika gagal, redirect ke halaman login.
403 Forbidden Akun dinonaktifkan atau akses ditolak Tampilkan modal/halaman pemberitahuan akun dinonaktifkan.
409 Conflict Email atau Username sudah terdaftar Beri tanda merah pada field email atau username di form registrasi.
429 Too Many Requests Melebihi rate limit (terlalu banyak hit) Tampilkan pesan: "Terlalu banyak permintaan, coba lagi beberapa saat".
2 Siklus Autentikasi & Refresh Token Rotation

User Service menerapkan sistem Dual-Token dengan keamanan tinggi:

  • Access Token: Berumur pendek (15 menit). Digunakan pada header setiap request terlindungi.
  • Refresh Token: Berumur panjang (7 hari). Disimpan aman untuk meminta Access Token baru.
  • Refresh Token Rotation: Setiap kali refresh token digunakan, token lama langsung dicabut dan diganti dengan pasangan token baru. Token lama yang sudah dipakai tidak dapat digunakan kembali.
Rekomendasi Penyimpanan di Frontend:
• Simpan accessToken di memory/state aplikasi (atau React context / Zustand / Pinia).
• Simpan refreshToken di HttpOnly Cookie (atau Secure LocalStorage / SecureStore jika mobile).

Diagram Alur Interceptor Token (Axios / Fetch)

[Frontend Request API]

[User Service Backend]

    Apakah Token Valid?

4 Implementasi Client Frontend (Axios Interceptor)

Berikut adalah template siap pakai untuk menangani token refresh otomatis pada project Next.js / React / Vue menggunakan Axios:

import axios from 'axios';

const api = axios.create({
  baseURL: 'http://localhost:3001/api/v1',
  headers: {
    'Content-Type': 'application/json',
  },
});

// Request Interceptor: Menambahkan Bearer Token
api.interceptors.request.use((config) => {
  const token = localStorage.getItem('accessToken');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

// Response Interceptor: Menangani Token Expired (401) & Auto Refresh
api.interceptors.response.use(
  (response) => response,
  async (error) => {
    const originalRequest = error.config;

    // Cek jika error 401 dan bukan request login/refresh itu sendiri
    if (
      error.response?.status === 401 &&
      !originalRequest._retry &&
      !originalRequest.url?.includes('/auth/login') &&
      !originalRequest.url?.includes('/auth/refresh')
    ) {
      originalRequest._retry = true;
      const refreshToken = localStorage.getItem('refreshToken');

      if (!refreshToken) {
        // Redirect ke login jika tidak ada refresh token
        window.location.href = '/login';
        return Promise.reject(error);
      }

      try {
        const { data } = await axios.post('http://localhost:3001/api/v1/auth/refresh', {
          refreshToken,
        });

        // Simpan token baru hasil rotasi
        localStorage.setItem('accessToken', data.data.accessToken);
        localStorage.setItem('refreshToken', data.data.refreshToken);

        // Ulangi request awal dengan token baru
        originalRequest.headers.Authorization = `Bearer ${data.data.accessToken}`;
        return api(originalRequest);
      } catch (refreshError) {
        // Sesi telah kedaluwarsa atau dicabut
        localStorage.removeItem('accessToken');
        localStorage.removeItem('refreshToken');
        window.location.href = '/login';
        return Promise.reject(refreshError);
      }
    }

    return Promise.reject(error);
  }
);

export default api;
